# Cresce+ Futuro | Análise de Dados com Power BI

Este repositório reúne projetos de análise de dados desenvolvidos dentro do meu trabalho com a **Cresce+ Futuro**.

A Cresce+ é uma plataforma de gestão e organização voltada a empreendedores e empresas, com foco em tornar informações, processos e decisões mais claros e acessíveis.

Meu trabalho com a organização começou como voluntariado e posteriormente passou a fazer parte da minha atuação como freelancer. Dentro desse processo, venho trabalhando na organização, tratamento e análise dos dados coletados pela Cresce+, transformando essas informações em dashboards no Power BI.

---

## Projetos

Atualmente, este repositório reúne dois dashboards.

### Bem-vinda(o) à Cresce+ Futuro!

Projeto voltado para entender melhor **quem está chegando à Cresce+**, analisando perfil, relação com empreendedorismo, interesses, motivações e preferências de comunicação.

**Principais pontos trabalhados:**

- análise exploratória;
- tratamento dos dados no Power Query;
- modelagem de dados;
- DAX;
- tratamento de perguntas de múltipla escolha;
- construção do dashboard.

**[Ver projeto →](./projetos/01%20-%20F1%20-%20Bem%20Vinda(o)%20%C3%A0%20Cresce%2B%20Futuro!/)**

---

### Queremos Ouvir Você!

Projeto voltado para analisar **a experiência dos participantes após as oficinas da Cresce+**.

O dashboard reúne avaliações sobre qualidade e utilidade das atividades, intenção de aplicação do aprendizado, participação, interesses para novas oficinas e relacionamento com a organização.

**Principais pontos trabalhados:**

- indicadores de avaliação;
- análise das oficinas;
- Power Query;
- modelagem de dados;
- DAX;
- tratamento de múltipla escolha;
- construção do dashboard.

**[Ver projeto →](./projetos/02%20-%20F2%20-%20Queremos%20Ouvir%20Voc%C3%AA!/)**

## Dados e privacidade

Os projetos originais foram desenvolvidos com dados reais da **Cresce+ Futuro**.

Esses dados permanecem privados.

Para apresentar o trabalho no portfólio, as versões disponíveis neste repositório utilizam **bases totalmente fictícias**, criadas apenas para demonstrar o tratamento dos dados, a modelagem, as medidas e o funcionamento dos dashboards.

Os resultados apresentados publicamente, portanto, **não representam os resultados reais da empresa**.
